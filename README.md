# Turnaround Time (TAT) Analytics

A Power BI proof of concept for reviewing turnaround time (TAT) at processing centres.

## Project file

- **`TAT Analysis.pbix`** — the Power BI report. Open it with Power BI Desktop.

## Data and refresh

The source CSV and Excel reports are intentionally excluded from this repository. To refresh the report, obtain the authorized source data through the appropriate internal channel and configure the report's data-source paths and credentials in Power BI Desktop.

Do not commit customer, operational, or otherwise confidential source data to this repository.

## Requirements

This project has no Python package dependencies. Power BI Desktop is required to open and work with the `.pbix` report. See [`requirements.txt`](requirements.txt).
